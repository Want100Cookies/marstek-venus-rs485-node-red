# Getting Started (HACS)

1. Install via HACS.
2. Restart Home Assistant.
3. Add the **Home Battery Control** integration.
4. Pick P1/grid sensor (W, positive import).
5. Add battery mappings (or Marstek preset).
6. Confirm panel loads and entities are created.
7. Run a safe first test at 800 W.
8. Enable Full control only after stop/charge/discharge checks.

Rollback path: disable integration control and continue with legacy Node-RED flow set.
